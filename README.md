# 칠성 미러마켓

한국 소비자 페르소나 수천 명이 사는 가상 시장에 신제품 콘셉트를 먼저 출시해 보고, 여러 시나리오(가격·패키지·문구·인플루언서) 중 **4주 뒤 가장 많이 팔릴 확률이 높은 안**을 통계적으로 고르는 시뮬레이터.

## 실행

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py          # 첫 실행 시 페르소나 데이터(약 220MB) 자동 다운로드
ant auth login                          # 선택: Claude로 LLM + SSR 응답 모드, 페르소나 대화 (또는 ANTHROPIC_API_KEY)
```

## 구조

| 파일 | 역할 |
|---|---|
| `mirror/consumer.py` | 페르소나 풀(NVIDIA Nemotron-Personas-Korea, 통계청 분포 기반) 로드, 연령×성별 층화추출, 반응 모델(규칙 기반 효용 / LLM 자유서술 → SSR) |
| `mirror/viral.py` | 멱법칙 팔로우 네트워크, 4주 일 단위 확산(게시물 영향력 지수 감쇠, 부정 후기 페널티), 분기비 n*, Bass 모형 적합 |
| `mirror/stats.py` | 표본 크기, 부트스트랩 CI, 두 비율 z검정, Holm 보정, Cohen h, 베이지안 1등 확률, TVD |
| `mirror/sim.py` | 요인설계 시나리오 × 몬테카를로 반복(공통 난수) → 결과 요약 |
| `app.py` | Streamlit 대시보드: 시나리오 순위 · 통계 검정 · 바이럴 확산 · 세그먼트 · 페르소나 대화 |

## 핵심 지표

- **승률**: 같은 난수 조건의 각 반복에서 4주 구매율 1위를 한 비율
- **설문 구매의향**: 5점 척도 4~5점 확률 (말) vs **4주 구매율**: 확산 시뮬레이션 결과 (행동)
- **바이럴 확률**: 초기 14일 게시물 1건당 직접 유발 구매 수(분기비 n*)가 1을 넘은 반복의 비율
- **말-행동 전환율**: 설문 의향 → 실제 구매 전환. 실제 출시 데이터로 보정해야 하는 핵심 파라미터

## 자체 검사

```bash
for m in stats viral consumer sim; do .venv/bin/python -m mirror.$m; done
```

## 실데이터 앵커 (기록 앵커 시민)
페르소나마다 **같은 성별·나이(±3세)·시도의 실제 응답자 기록**을 hot-deck 통계적 매칭으로 붙인다.
출처: 한국농촌경제연구원 [2025 식품소비행태조사](https://krei.re.kr/foodSurvey/page/460) 성인가구원 원자료(n=5,874, 가중치 포함). 처음 실행 시 자동 다운로드(`mirror/records.py`).

- 성향 척도(실측 상관으로 구성, Cronbach α): 새로움 추구 .68 · 알뜰 계획형 .75 · 건강 관심 .60 · SNS 활용 .85
- ML: '제로음료 월 2회 이상' 가중 로지스틱 회귀, 5겹 CV AUC 0.741 (인구통계만 0.722)

## 검증 현황 (2026-11-23 정정)
이전 판의 "시뮬레이터 3.6%p vs LLM 33.6%p", "λ=0.9 우도비 390", "시간 예측이 기준선보다 낫다"는 **철회**한다.

| 항목 | 결과 | 해석 |
|---|---|---|
| 집단별 제로음료 이용률 (KREI 절반으로 나머지 절반, 5시드) | 시뮬레이터 3.36%p · 훈련 절반의 집단평균 복사 3.23%p | 같은 문항의 답을 복사하는 구조라 **예측력의 증거가 아님**. 정답을 본 적 없는 LLM(33.6%p)과의 비교도 불공정 |
| 선택모델 1순위 5겹 CV | logloss 2.273 (점유율만 2.330) · top3 52.8% (50.4%) · top1 개선 없음 | 개선은 작음 |
| 2023~24 학습 → 2025 집단 점유율 오차 | 모델 2.07%p · 2024 그대로 1.56%p (커피 7.02 vs 4.59) | **기준선에 짐** |
| 범주 제외(LOCO) 집단 상관 | 가당 탄산 .99 · 발효유 .96 · 흰우유 .94 · 제로 탄산 .80 · 주스 .71 / 탄산수 −.99 · 가공우유 −.59 · 음료전문점 −.55 · 차 −.44 · 이온 −.38 | 절반 가까이 실패. 규제값을 이 시험으로 골라 수치는 낙관적 |
| 중첩 로짓 λ | 1.0 (일반 로짓) | 묶음 대체 효과 근거 없음. 잠식률은 미검증 |
| 출시 백테스트 | 펩시 2.9% (2.4~4.0) · 밀키스 9.2% (7.7~20.6) | 1인당 구매 개수는 **근거 없는 가정**이고, 범위를 벗어난 뒤 효용 기준점을 바꿔 맞췄음 → 독립 검증 아님. 실적은 검색 요약만 확인 |
| 개인 트윈 (n=60) | ML 60% · 집단 최빈값 52% · LLM 35% | 표본이 작아 ML과 최빈값 차이는 불확실 |

원인: 순위 데이터 15%가 이미 빠진 범주를 다시 고른 행(중복 응답)이라 목적함수가 무한대였음 → 수정(MODEL_VERSION 2). 학습은 4초(이전 "50분" 설명은 오류).

## 미디어 대응실 (`mirror/media.py`, `mirror/media_ui.py`)
수집 → laya-ko 로컬 분류 → 추세·위험 감지 → 대응 초안(사람 승인, 자동 게시 없음).

- 실행: `python -m mirror.media collect` (1회) · `watch 600` (10분마다) · `wiki` (위키 조회수) · `check` (자체검사). 대시보드 왼쪽 **화면 → 미디어 대응실**
- 모델: [2nugu/laya-ko](https://huggingface.co/2nugu/laya-ko)(Apache-2.0) 를 `data/models/laya-ko` 에 둔다(git 제외)
- 키 없이 23개 소스: 빙 뉴스, 식품·소비자 전문지, 식약처, 경제지, 구글 트렌드, 블루스카이, 마스토돈, 커뮤니티 10곳. `YOUTUBE_API_KEY`, `APIFY_TOKEN` 을 `.env` 에 넣으면 유튜브·Threads·릴스·틱톡이 켜진다(**미시험**). 네이버·쿠팡은 약관 위험 때문에 `ALLOW_NAVER=1`, `ALLOW_COUPANG=1` 을 명시해야 켜진다
- 모든 웹 요청은 robots.txt 통과분만, 소스당 10분 1회, 작성자 아이디 미저장

실측(2026-11-24): 24개 소스 18초 · 분류 502건 134초 · laya 정확도(수집 글 42건, 1인 라벨) 유형 62%(최빈값 48%), 감정 67%(최빈값 67%). 안전 판정은 실데이터에서 무의미해 키워드 규칙만 사용.
위키 조회수 추세 검증(10개 키워드): 급등 다음 주 평소보다 높을 확률 75%, 더 오를 확률 21% → 관심은 남지만 대개 꺾인다.

### 감정: Level 모델 (2026-11-24)
유형은 laya-ko, 감정은 Level 앱의 2단계 모델(관문 [Seonghaa](https://huggingface.co/Seonghaa/korean-emotion-classifier-roberta) + 세부 [KOTE 44감정](https://huggingface.co/searle-j/kote_for_easygoing_people), 둘 다 MIT)을 `data/models/level-emotion` 사본으로 실행한다(Mac 전용, git 제외, 없으면 건너뜀).

| 시험 | laya | Level |
|---|---|---|
| 수집한 SNS 글 97건(예측 보지 않고 1인 라벨, 복수 정답) | 61.9% | 67.0% (전부 중립 71.1%, McNemar p=0.42) |
| 같은 글, 대표 정답 매크로 F1 | 0.466 | 0.532 (전부 중립 0.236) |
| 네이버 쇼핑 리뷰 300건, 판정한 글만 | 92.9% (확신 .9, 89%의 글) | 95.3% (86%의 글) |
| 네이버 영화평 300건, 판정한 글만 | 83.4% (80%) | 86.2% (82%) |

두 출력을 합친 로지스틱 F1 0.567(반복 5겹 CV). 라벨을 30→77건으로 늘려도 F1이 오르지 않아 얇은 재학습은 효과가 없다. KOTE 는 온라인 댓글로 학습돼 공개 리뷰와 겹칠 수 있다.
